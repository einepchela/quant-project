# quant-project
В данном проекте планируется на основе данных московской биржи за 2015-2025 применить средства классического машинного обучения для прогнозирования цен акций в экстремальных условиях и выявление наиболее значимых признаков или их комбинаций в таких ситуациях.

Данные: дневная рыночные показатели 21 тикера (SBER, GAZP, LKOH, NVTK, MGNT, VTBR, ROSN, MOEX, PLZL, GMKN, TATN, TRNFP, SBERP, SNGSP, PHOR, AFLT, SNGS, MAGN).
Признаки: ряд классических признаков для анализа временных рядов из стандартов QUANT.
Метрики: IC, IC-IR, IC-std, %IC>0.
Целевые переменные: пока модель градиентного бустинга хорошо обучилась на target_reg - относительная разность между ценами закрытия на выбранном горизонте (5 дней).

Модели обучаются на временном интервале 2015-2021. Тестирование проходит в жёстких условиях 2022 года и далее вплоть до 2025. Пока установить набор признаков, которые хорошо работают в стресс-режиме 2022 года, не удалось. Тем не менее, в спокойных условиях градиентный бустинг показывает неплохую предсказательную способность. Можно попытаться применять алгоритмы снижения размерности для составления более информативных комбинаций признаков.
